客户端选择与官方下载指引

飞鱼以机场订阅为核心，强调按系统选择成熟客户端后导入配置。请从各客户端原作者或正规应用商店获取安装包，再回到飞鱼官网说明完成订阅导入，避免非官方渠道的二次打包。

Windows

推荐 Clash Verge 或 v2rayN。安装后新建订阅，粘贴飞鱼提供的 Clash 或 V2Ray 链接并更新节点，选择规则模式即可分流。

macOS

常用 ClashX Meta 或 Surge。导入订阅后开启系统代理，按域名规则走加速节点，本地流量保持直连。

Android

推荐 Clash Meta for Android 或 v2rayNG。允许 VPN 权限后更新配置，建议开启绕过中国大陆地址以节省流量。

iOS

可使用 Shadowrocket、Stash 或 Quantumult X。通过 App Store 安装正版后添加订阅，按需开启 MITM 与分流策略。

Linux 与路由器

可使用 Clash Meta 内核或兼容订阅的网关固件。团队版支持定制路由，适合把飞鱼节点下发到多台终端。

操作说明

按照纵向步骤完成配置。全程只需订阅链接与客户端，无需在本页填写表单。

1

确认套餐

对照流量、设备数与线路类型，在基础版、旗舰版、团队版中选择一档。长期使用优先考虑年付优惠。

2

获取飞鱼订阅

通过飞鱼官方渠道完成订阅后，复制 Clash、V2Ray 或 Surge 格式链接。请只在官网公示的入口获取，避免转发来源不明的地址。

3

下载并安装客户端

打开「客户端选择」对应系统说明，安装正版工具。本站提供配置方法，不托管可执行文件。

4

导入并更新节点

在客户端粘贴订阅，执行更新。确认节点列表出现后，选择延迟较低的线路，开启系统代理或 VPN 模式。

5

按规则使用

建议开启分流：国内直连、跨境走飞鱼节点。遇到异常时切换节点或重新更新订阅，旗舰版可走优先工单。

常见问题

飞鱼官网提供哪些服务？

飞鱼官方网站介绍机场订阅套餐、客户端选择与导入步骤。用户可在此了解基础版、旗舰版与团队版差异，并按指南完成网络加速配置。

客户端下载应该去哪里获取？

请从 Clash、v2rayN、Shadowrocket 等工具的原作者站点或正规应用商店下载。飞鱼提供订阅与配置说明，不建议使用来路不明的「一键包」。

如何把飞鱼订阅导入客户端？

复制订阅链接，在客户端的订阅或配置页面粘贴并更新。Windows 与 Android 常见 Clash 系列，iOS 常见 Shadowrocket 或 Stash，导入后选择节点连接即可。

各套餐流量和设备数如何计算？

基础版每月 100GB、3 台设备；旗舰版每月 300GB、5 台设备；团队版每月 1000GB、20 台设备。同时在线超出上限时，部分终端可能无法保持连接。

年付比月付更划算吗？

是。基础版年付 ¥150、旗舰版年付 ¥350、团队版年付 ¥850，相当于降低约两个月费用，适合已确认长期使用飞鱼机场的用户。

连接失败或速度波动时怎么处理？

先核对系统时间、订阅是否过期以及是否被其他代理占用端口，然后更新订阅并更换节点。旗舰版含 7x24 优先工单，团队版可联系专属客户经理。
